# SQL Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) using SQL to understand datasets, identify patterns, discover trends, and extract meaningful business insights.

The analysis uses SQL queries to explore data, evaluate business performance, and support data-driven decision-making.

## 🎯 Project Objectives

- Explore datasets to understand their structure and characteristics.
- Analyze key business metrics and performance indicators.
- Identify trends and patterns in the data.
- Examine customer and product performance where relevant to the dataset.
- Identify potential data quality issues.
- Generate meaningful insights using SQL queries.

## 🛠️ Tools & Technologies

- **Microsoft SQL Server** — Database management and data analysis.
- **SQL Server Management Studio (SSMS)** — Writing and executing SQL queries.

## 📊 SQL Concepts Used

- Aggregate Functions: `SUM()`, `AVG()`, `COUNT()`, `MIN()`, `MAX()`
- Filtering and Sorting: `WHERE`, `ORDER BY`
- Grouping Data: `GROUP BY`, `HAVING`
- Joins: `INNER JOIN`, `LEFT JOIN`
- Conditional Logic: `CASE WHEN`
- Subqueries
- Window Functions
- Date and Time Functions
- NULL Value Handling

*Note: Keep only the concepts you have actually used in your SQL scripts.*

## 🔍 Analysis Performed

The project may include the following analyses, depending on the available dataset:

1. **Data Exploration** — Examine tables, columns, records, and data types.
2. **Data Quality Analysis** — Check for missing values, duplicates, and inconsistencies.
3. **Metric Analysis** — Calculate totals, averages, counts, and other relevant metrics.
4. **Trend Analysis** — Investigate changes over time.
5. **Category Analysis** — Compare performance across relevant categories.
6. **Ranking Analysis** — Identify top-performing and low-performing items.
7. **Business Insights** — Summarize findings that can support decision-making.
